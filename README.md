📈 Zerodha Clone – Full Stack Trading Dashboard

A full-stack Zerodha-inspired trading dashboard built from scratch with real-time market data, modern UI, and scalable backend architecture.

This project simulates core trading platform features such as watchlist, live prices, positions, holdings, margin summary, and P&L calculations.

---

🚀 Features

• Live watchlist with real-time stock prices  
• Positions, holdings, orders, and funds dashboard  
• Real-time P&L and percentage change updates  
• Doughnut & bar charts for portfolio visualization  
• Smooth UI interactions and hover actions  
• Auto-refreshing data without page reload  
• Clean, responsive, production-style layout  

---

🧩 Tech Stack

Frontend  
• React.js  
• JavaScript (ES6+)  
• Material UI  
• Chart.js (Bar & Doughnut Charts)  
• Axios  

Backend  
• Node.js  
• Express.js  
• RESTful APIs  

Database  
• MongoDB  
• Mongoose  

Live Market Data  
• Yahoo Finance API (real-time stock prices)

---

⚙️ Project Architecture

• Frontend handles UI, state management, charts, and user interactions  
• Backend manages APIs, business logic, calculations, and data flow  
• MongoDB stores orders, positions, holdings, and funds  
• Yahoo Finance API provides live market prices  

---

📊 Dashboard Modules

• Watchlist (live prices with up/down indicators)  
• Positions (LTP, quantity, average price, P&L)  
• Holdings summary  
• Margin & funds overview  
• Portfolio doughnut chart

🛠️ How to Run Locally

1️⃣ Clone the repository
```bash
git clone https://github.com/RajuRacha17/Zerodha-clone.git


2️⃣ Install backend dependencies
cd backend
npm install
npm start

3️⃣ Install frontend dependencies
cd frontend
npm install
npm start


4️⃣ Environment Variables

Create a .env file inside backend:
MONGO_URI=your_mongodb_connection_string
PORT=3002
